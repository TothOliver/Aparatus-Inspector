## About This Game

*Apparatus Inspector* is a retro OS survival horror simulation set in a subterranean research complex in 1998.

Stationed inside an isolated observation booth, your job is to inspect incoming synthetic units. Using a desk-bound CRT terminal running Aethelgard OS, you must evaluate each unit's dialogue, telemetry data, and system signatures to determine whether to **APPROVE** them or **EXTERMINATE** them.

### Manage Physical Facility Survival
The terminal is only half your responsibility. Track patrolling disposal drones on live CCTV, manage hydraulic security doors, and control office lighting—all while balancing a strict emergency room power budget. When hostiles approach, cut terminal power, douse the lights, and hide.

### Key Features

* **Diagnostic Investigation:** Detect subtle anomalies using dialogue evaluation, spec sheet cross-referencing, and AE-DOS terminal hash verification.
* **Simulated 1998 OS:** Fully interactive Aethelgard OS featuring resizable applications, an intranet browser, system terminal, security feeds, and desktop utilities.
* **Dual-Layer Survival Loop:** Balance software inspection duties against physical room management, hydraulic door locks, and power allocations.
* **Active Environmental Threat:** Evade the patrolling Hunter drone by shutting off lights, powering down displays, and remaining undetected.
* **Branching Shift Outcomes:** Your daily inspection accuracy and diagnostic choices determine narrative progression and unlock multiple distinct endings.
